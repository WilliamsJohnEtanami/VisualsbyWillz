# VisualzByWillz
React + TypeScript + Vite + Tailwind portfolio.

## Run locally
`npm install` then `npm run dev`.

## Production
`npm run build`; deploy the `dist` folder to a static host.

## Content
Edit `src/content.ts` for brand details, services, and approved portfolio projects. Add media to `public/assets`. The work section and navigation appear automatically once at least one project is added. MP4 videos and photography galleries are supported. The original supplied logo is in `public/assets/logo.jpg`.

## Content needed before final launch
- Authentic projects, media, titles, descriptions and exact creative roles; approval to display each.
- Optional behind-the-scenes images and showreel. The supplied portrait is included in the About section.
- Confirm the registered legal business name and registration prefix against the full certificate.
- Business email/phone if desired. Instagram links use @visualzbywillzmedia. TikTok is not displayed. Google Drive portfolio is linked from the hero, navigation and contact section.
- Form delivery destination/service if a contact form is desired. No form currently collects data.

No sample clients, testimonials, prices, equipment claims or project statistics are published. The hero shows three supplied photographs cropped from Instagram screenshots. Carousel automatically advances every five seconds and pauses on hover/focus, offers manual navigation and a pause control, and respects reduced-motion preferences.
